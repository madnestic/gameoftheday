Документ для передачи проекта в Claude Code. Содержит весь контекст: что построено, какие приняты решения, что планируется дальше.

---

## Что это

Сайт-хаб с мини-играми, играющимися прямо в браузере. Принципиально без скачиваний, без аккаунтов, без рекламы, без бэкенда. Цель — иметь несколько простых одноэкранных игр, которые можно открыть по ссылке и сразу играть.

Сейчас в проекте одна готовая игра — **Pongonoid** (гибрид Pong и Arkanoid против ИИ) — и заготовлены слоты под ещё две игры.

---

## Структура проекта

Один файл: `index.html` (~50 KB). Внутри — HTML, CSS, JS и звуки через Web Audio API. Внешних зависимостей нет, кроме Google Fonts (Major Mono Display, JetBrains Mono).

```
index.html
├── <style>     — CSS для хаба и игрового экрана
├── <body>
│   ├── .hub             — главная страница со списком игр
│   └── .game-screen     — экран запущенной игры (canvas + HUD)
└── <script>
    ├── Hub navigation   — переключение хаб ↔ игра
    └── Pongonoid module — IIFE с логикой первой игры
```

Каждая игра — изолированный JS-модуль (паттерн `const Pongonoid = (() => { ... return { init, stop } })()`). Новые игры добавляются по тому же шаблону: новый модуль + новая карточка в хабе с `data-game="<name>"` + ветка в обработчике клика.

## Эстетика

Чёрно-белая минималистичная. Принципы:

- Всё обводкой, кроме двух исключений: ракетка игрока (яркая случайная заливка при каждом старте) и блоки на стороне ИИ (чёрная заливка)
- Шрифты: `Major Mono Display` для заголовков, `JetBrains Mono` для интерфейса
- Тонкая едва заметная сетка фона (subtle paper-grid)
- Никаких градиентов, теней, неона. Бумажная графика.

Палитра ярких цветов для ракетки игрока (выбирается случайно):
```js
['#ff2e6e', '#ff6b00', '#ffd400', '#7cff3a', '#00d4ff',
 '#1f6bff', '#9b51ff', '#ff3a3a', '#00e5a0', '#ff9ed1']
```

## Pongonoid — правила

### Поле и объекты

| Параметр | Значение |
|---|---|
| Логические размеры canvas | 480 × 720 (px, автомасштаб под экран) |
| Ракетка | 90 × 8 px, отступ от края 18 px |
| Шарик | радиус 6 px |
| Блок | 40 × 18 px |
| Зазор между блоками | 3 px |
| Колонок в ряду | 12 |

### Управление

- Мышь / палец двигают ракетку по горизонтали
- Клик / тап запускает прилипший к ракетке шарик
- Шарик игрока стартует прилипшим, шарик ИИ запускается автоматически через ~800 мс

### ИИ

- Двигается со скоростью 3.6 px/кадр (медленнее шарика)
- Целится с ошибкой: при каждом отскоке выбирает рандомное смещение от центра ракетки в диапазоне ±45% от её ширины
- Между отскоками ошибка чуть «дрожит», добавляя живости
- Это даёт удары под разными углами и иногда — промахи на быстрых шариках

### Поле блоков

- В начале — 4 ряда блоков по центру (2 над серединой, 2 под)
- Каждые 14 секунд в центре появляется 2 новых ряда, существующие блоки сдвигаются от центра наружу
- Блоки, подошедшие слишком близко к ракетке, удаляются
- Блоки выше середины поля рисуются чёрной заливкой (стиль ИИ), ниже — обводкой (стиль игрока). Стиль определяется текущей позицией, поэтому при сдвиге блок меняет вид

### Шарик

- Скорость 5.6 px/кадр
- Каждый шарик помнит:
  - `owner` — кто его изначально запустил
  - `lastHitBy` — кто последним отбил его ракеткой (для системы очков)
- При отскоке от ракетки `lastHitBy` обновляется

### Очки

| Событие | Очки |
|---|---|
| Блок твоим шариком (lastHitBy == owner) | +10 тебе |
| Блок «украденным» шариком (lastHitBy != owner) | +10 тому, кто отбил последним; +20 владельцу шарика (×2) |
| Шарик прошёл за ракетку соперника | +100 тому, чей был последний удар |
| Шарик улетел за свою ракетку, последний удар твой | −50 (автогол) |

**Важно:** всплывающие цифры на поле показываются только для очков игрока. Очки бота меняются только в верхней панели HUD.

### Возрождение шарика

Когда шарик улетает за поле, проверяем: есть ли у каждой стороны хоть один шарик на её половине (по вертикальной позиции; прилипший шарик считается на стороне владельца). Логика:

- Если у одной из сторон шариков нет → выбывший возрождается у неё, его `owner` обновляется на новую сторону
- Иначе → возрождается у изначального владельца (`ball.owner`)

Это решает проблему «оба шарика на одной стороне» — пропущенный шарик уйдёт к тому, у кого пусто.

### Конец игры

Сейчас режим бесконечный. Игра не заканчивается по очкам, выход — кнопка BACK в хабе. Можно добавить порог (первый до 500 побеждает) — пока не реализовано.

## Звуки

Все звуки генерируются через Web Audio API на лету, без mp3-файлов. Базовая функция `playDrop()` создаёт «капельный» звук — короткий синусный тон с быстрым понижением высоты от ×1.6 до базы, плюс высокая обертонная гармоника для шиммера.

| Событие | Параметры |
|---|---|
| Удар по блоку | freq зависит от Y, gain 0.16, dur 0.18s |
| Удар ракетки | чуть глубже, gain 0.20, dur 0.22s |
| Стена | короче и тише, gain 0.10, dur 0.12s |
| Гол | двойной восходящий звон 1100→1500 Гц |
| Автогол / штраф | низкий тон 220 Гц |

Высота звука зависит от Y-координаты удара: чем выше на поле — тем выше тон. Плюс рандом ±3-7% чтобы серия ударов не звучала идентично.

Аудио активируется при первом нажатии START (требование браузеров — без user gesture звук заглушен).

## Адаптивность и устройства

- `touch-action: none` и `overscroll-behavior: none` на body, чтобы не дёргался экран при свайпе
- `position: fixed` на body для блокировки скролла страницы
- Тач-события на канвасе в режиме `passive: false` с `preventDefault()` — нужно для iOS, иначе страница пытается зумиться
- Canvas автомасштабируется под размер контейнера, сохраняя соотношение 480×720
- На узких экранах (≤600px) сетка карточек становится в одну колонку, заголовок игры в HUD прячется

## Журнал решений (что и почему)

Хронология значимых решений — на случай если будет соблазн откатить/переделать:

1. **Чёрно-белая обводочная эстетика** — выбрано вместо неонового киберпанка. Обводки везде, кроме ракетки игрока и блоков ИИ.
2. **Ряды появляются в центре** — раньше прибавлялись с краёв (с каждой стороны поочерёдно), это был неудобный эффект «давит на ракетку». Сейчас ряды в центре раздвигают блоки наружу.
3. **Зазор между блоками 3 px** — начинали с 2, потом 1, потом подняли до 3 для воздушности.
4. **Скорость шарика 5.6** — начинали с 4.2, повысили по запросу.
5. **Удар бота с разбросом** — раньше бот всегда отбивал ровно центром ракетки и шарик всегда шёл вертикально. Теперь рандом ±45% ширины.
6. **Интервал новых рядов 14 сек** — было 7, увеличили вдвое чтобы не давило.
7. **Система очков вместо жизней** — начинали с 3 жизней у каждого. Переделано на счёт. Игра стала бесконечной, без явного «победил/проиграл».
8. **Очки за блок ×2 владельцу** — добавлено правило: если бьёшь чужой шарик и попадаешь по блоку, владельцу тоже капает (двойная награда), чтобы поощрять «крадёные» удары для обоих.
9. **Попапы с цифрами только у игрока** — раньше показывались для обоих, спамило цифрами от бота. Теперь видно только свои очки.
10. **Шарик возвращается владельцу, но с исключением** — если у одной из сторон нет шариков на её половине, пропущенный шарик уйдёт к ней независимо от изначального владельца.
11. **Случайный цвет ракетки** — выбирается из 10 ярких цветов при каждом старте игры.
12. **Звуки-капли** — Web Audio, без файлов, чтобы оставить один HTML-файл.
13. **Убран центральный пунктир** — не нужен после введения визуального различия блоков.

## Как продолжать в Claude Code

1. Положить `index.html` в репозиторий
2. При запросах на правки — указывать какую часть менять (хаб / Pongonoid / стили / звуки)
3. После каждой правки имеет смысл проверять синтаксис JS — например запуском `node --check` на извлечённом скрипте, или просто открытием файла в браузере
4. Для добавления новой игры — копировать паттерн модуля `Pongonoid`, регистрировать карточку в хабе

### Конвенции в коде

- Все размеры и константы вынесены в начало модуля Pongonoid
- Используется логическая система координат 480×720, canvas масштабируется CSS-ом
- Координаты `+0.5` при `strokeRect` — для пиксель-перфектных линий
- Цвета: `#000` ink, `#fff` bg, плюс палитра `PLAYER_COLORS`
- Никаких внешних библиотек — всё ваниль
